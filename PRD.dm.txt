# PRD: AI Bank Statement to Excel Converter

## Project Name

**Bank Statement Intelligence (BSI)**

## Objective

Build a desktop and web application that intelligently reads PDF bank statements from any bank, accurately extracts every transaction without skipping a single line, and converts the statement into a clean, structured Excel workbook suitable for accounting, auditing, reconciliation, and financial analysis.

This is NOT a simple PDF converter.

It is an AI-powered statement parser that understands the layout of each bank statement.

---

# Primary Goal

The application must achieve over **99.9% extraction accuracy**.

It must never skip:

* Beginning Balance
* Value Date
* Transaction Date
* Description
* Reference Numbers
* Debit Amount
* Credit Amount
* Running Balance

Every transaction must appear exactly once.

## Success Criteria

The final application should produce an Excel file that is as clean and accurate as if a professional accountant manually typed every transaction, while completing the task in minutes instead of hours. It must preserve all financial data exactly as shown on the original statement, validate balances mathematically, and clearly report any uncertainty instead of silently omitting transactions.

To make this even more powerful, you can ask OpenCode to build it using a **hybrid AI extraction engine** that combines rule-based parsing, OCR, computer vision, and a large language model for layout understanding. This approach is significantly more robust than relying on OCR or PDF parsing alone and is better at handling messy, scanned, or inconsistent bank statements.
